# Task & Project Manager

Терминално C++17 приложение за управление на проекти и задачи.

## Реализирани функционалности

- Управление на проекти: създаване, преглед, редакция, изтриване
- Управление на задачи: създаване, преглед, редакция, изтриване
- Проследяване на статус на задача
- Приоритет на задача
- Краен срок за задача
- Търсене на задачи по ключова дума
- Филтриране на задачи по статус или приоритет
- Сортиране на задачи по краен срок или приоритет
- Статистика за проект
- Записване и зареждане от файл

## Използван дизайн

- `Date` — валидация и форматиране на дати
- `BaseEntity` — абстрактна базова класа с `id` и `createdAt`
- `Project` и `Task` — наследяват `BaseEntity`
- `TaskManager` — координира бизнес логиката и менютата
- `FileManager` — сериализация и десериализация на проектите
- `Priority` и `TaskStatus` — enum-и за валидни състояния
